# 日常｜我的每日行事曆

一個以「一天一頁」為概念的私人網頁行事曆，包含：

- 依日期新增、完成與刪除待辦事項
- 自動計算當日完成進度
- 記錄今天做了哪些事
- 撰寫今日心得
- 自動將每一天的內容保存在目前瀏覽器
- 支援手機與桌面版面

## 在本機執行

需要 Node.js 22.13 以上版本。

```bash
npm install
npm run dev
```

開啟終端機顯示的本機網址即可使用。

## 發佈與自訂網域

這個資料夾可以直接建立成 GitHub repository，用來保存與管理網站原始碼。正式網站可由相容的網站託管服務建置，再於託管服務中綁定你的自訂網域。

目前的每日資料使用瀏覽器的 `localStorage` 保存：不需要帳號或資料庫，但資料不會在不同瀏覽器或不同裝置間同步。清除瀏覽器網站資料也會清除紀錄。

## 建置正式版本

```bash
npm run build
```
