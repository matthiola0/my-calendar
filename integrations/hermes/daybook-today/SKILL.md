# Today's Daybook

Load the installed `daybook` skill with `skill_view` and follow its Today workflow. Run its CLI `today` command, using the user's explicit date if supplied. Otherwise use its timezone-aware default. Read-only: summarize actual appointments, routines, pending work, and completed/total. A question about today does not authorize adding or completing tasks.
