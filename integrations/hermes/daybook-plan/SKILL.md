# Arrange Daybook

Load the installed `daybook` skill with `skill_view` and follow its Arrange / plan workflow. Read planning context and every target date before writes. Account for routines, fixed appointments, deadlines, sections, and active cycle phases. A bare invocation produces a proposal for today; use an explicit range if supplied. A request to arrange/save authorizes the matching additions, while a request for suggestions stays read-only. Read back saved dates. Never silently reschedule existing commitments or treat task counts as available hours.
